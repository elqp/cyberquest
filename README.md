# Cyber Quest

A single-file browser maze game for cybersecurity-awareness training.

Three worlds, each with its own maze, look and music:

- **Office: Buay Tahan Tech Pte Ltd** - corporate security habits (tech, upbeat music)
- **Cafe: Kopi Theory** - personal wifi and password security (happy cafe beat)
- **Island: Coco Crab Club** - phishing, pretexting and baiting (ukulele)

Answer 6 checkpoint questions in each world. The wall around the glowing master key then fades away. Collect the key to open the exit. Collect all 3 keys to unlock the vault and reach Cybersecurity Mastery: Level 1.

Move with the arrow keys, WASD or the on-screen control panel.

Open `index.html` in a browser, or serve the repo with GitHub Pages. No build step, no dependencies.
